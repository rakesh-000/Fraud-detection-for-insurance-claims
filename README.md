# Insurance Claims Fraud Detection System

A runnable machine-learning demo for identifying potentially suspicious insurance claims. It includes data preprocessing, model training, evaluation, a Flask prediction API, prediction logging, and a lightweight web dashboard.

## Features
- Random Forest classifier with preprocessing for numeric and categorical fields
- Handles class imbalance using SMOTE when available and appropriate
- Saves the trained pipeline with Joblib
- Flask API for claim predictions and configurable probability threshold
- Dashboard with summary metrics and recent prediction logs
- Sample synthetic dataset so the project can run without a private or external dataset

> **Important:** The included dataset is synthetic and intended only to demonstrate the workflow. Model scores from it are not evidence of real-world fraud-detection performance. Predictions are investigation signals, not proof of fraud or a basis for automatically denying claims.

## Requirements
- Python 3.10+
- pip

## Quick start (Windows)
```powershell
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python train.py
python app.py
```
Open http://127.0.0.1:5000 in your browser.

## Quick start (macOS/Linux)
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python train.py
python app.py
```

## Use your own dataset
Replace `data/claims.csv` with your authorized dataset. The target column must be named `fraud` and contain 0 for genuine and 1 for fraudulent claims. Update `NUMERIC_FEATURES` and `CATEGORICAL_FEATURES` in `train.py` to match your columns. Do not use personally identifiable data in a public repository.

## API
### `POST /api/predict`
Example request:
```json
{
  "claim_amount": 25000,
  "policy_age_days": 365,
  "claim_delay_days": 12,
  "incident_hour": 18,
  "num_previous_claims": 2,
  "vehicle_age": 5,
  "claim_type": "collision",
  "incident_location": "urban",
  "police_report": "yes",
  "witness_present": "no"
}
```
Example response:
```json
{
  "prediction": "Potential Fraud",
  "fraud_probability": 0.71,
  "risk_level": "High",
  "threshold": 0.5,
  "note": "Screening result only; human review is required."
}
```
The probability shown is illustrative; actual output depends on the trained model.

### `POST /api/threshold`
```json
{"threshold": 0.65}
```

### `GET /api/metrics`
Returns training-set split evaluation metrics saved by `train.py`.

### `GET /api/history`
Returns the latest prediction log entries.

## Model pipeline
1. Load and validate labeled claim records.
2. Split data into training and test partitions.
3. Preprocess numeric and categorical columns.
4. Apply SMOTE to training data only when available and applicable.
5. Train a Random Forest classifier.
6. Evaluate with precision, recall, F1-score, ROC-AUC and a confusion matrix.
7. Save the full fitted pipeline and metrics.
8. Serve predictions through Flask and log outcomes without storing raw claim payloads.

## Security and responsible use
- Use authentication, authorization, HTTPS, retention policies and access controls before production deployment.
- Avoid logging sensitive claim details.
- Validate API inputs and monitor false positives and false negatives.
- Never automatically reject a claim based only on this model.
